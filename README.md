Приложение для заучивания иностранных слов с использованием карточек и адаптивной тренировки.
Функционал:
- добавление новых слов и их перевод
- возможность изменять или удалять слово
- тренеровка с адаптивным подбором слов
- учет статиски верных или неверных ответов
- сохранение слов в тестовый файл (words.txt)
Как собрать и запустить:
1. Установить необходимое ПО
- MinGW-w64 (или любой другой компилятор С++ с поддержкой WinAPI)
- CMake
- VS code (или любая другая IDE)
2. Затем вы клонируете данный репозиторий (например в VS code) по ссылке: git clone https://github.com/Bratok24/MyDictionaryApp.git
cd MyDictionaryApp
3. Открываете его в VS code
4. Затем собираете проект (нажать кнопочку Build можно использовать команду ctrl+shift+P)
5. После этого, можно запускать проект
